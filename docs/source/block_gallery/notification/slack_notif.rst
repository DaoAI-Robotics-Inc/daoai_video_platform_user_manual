.. _通知设置:

通知设置
==================

简介
----

Slack通知

输入 / 输出
-----------

- 输入：事件数据
- 输出：发送状态

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - webhook_url
     - Slack Webhook URL
     - 无
   * - channel
     - 频道名称
     - #general

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 配置Slack Webhook URL。
3. 点击保存。

注意事项
--------

- 需要在Slack workspace中创建Webhook。
