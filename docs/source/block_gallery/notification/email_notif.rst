.. _邮件通知:

邮件通知
==================

简介
----

邮件通知

输入 / 输出
-----------

- 输入：事件数据
- 输出：发送状态

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - recipients
     - 收件人列表
     - 无
   * - subject
     - 邮件主题
     - 报警通知
   * - include_image
     - 是否包含图像
     - true

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 配置收件人和邮件主题。
3. 点击保存。

注意事项
--------

- 需要预先配置SMTP服务器。
