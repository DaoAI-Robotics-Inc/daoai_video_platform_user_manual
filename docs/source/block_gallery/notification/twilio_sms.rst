Twilio短信通知
==================

简介
----

通过Twilio短信服务发送通知

输入 / 输出
-----------

- 输入：事件数据
- 输出：发送状态

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - to_number
     - 接收电话号码
     - 无
   * - message_template
     - 消息模板
     - 无

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 配置Twilio账号和接收号码。
3. 点击保存。

注意事项
--------

- 需要Twilio账号和API密钥。
