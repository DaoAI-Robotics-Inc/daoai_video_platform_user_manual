图像预处理
==================

简介
----

调整、翻转或旋转图像

输入 / 输出
-----------

- 输入：图像
- 输出：处理后的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - resize
     - 调整大小（宽x高）
     - 无
   * - rotate
     - 旋转角度（度）
     - 0
   * - flip
     - 翻转方式（horizontal/vertical/both）
     - 无

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 配置调整大小、旋转、翻转参数。
3. 点击保存。

注意事项
--------

- 常用于模型输入预处理。
