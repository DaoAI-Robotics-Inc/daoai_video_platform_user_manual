.. _图像轮廓:

图像轮廓
==================

简介
----

显示设置

输入 / 输出
-----------

- 输入：图像
- 输出：轮廓坐标

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - mode
     - 轮廓模式（external/all）
     - external

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择轮廓模式。
3. 点击保存。

注意事项
--------

- 用于形状检测和边缘提取。
