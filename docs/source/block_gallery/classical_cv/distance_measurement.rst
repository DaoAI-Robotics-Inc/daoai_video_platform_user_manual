距离测量
==================

简介
----

计算两个边界在二维平面上的距离

输入 / 输出
-----------

- 输入：两组坐标点
- 输出：距离值

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - unit
     - 单位（pixel/cm/m）
     - pixel
   * - calibration
     - 标定参数
     - 无

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 配置单位和标定参数。
3. 点击保存。

注意事项
--------

- 需要相机标定才能测量真实距离。
