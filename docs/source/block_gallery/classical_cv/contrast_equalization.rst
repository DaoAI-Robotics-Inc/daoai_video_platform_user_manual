对比均衡
==================

简介
----

对输入图像应用对比度均衡处理

输入 / 输出
-----------

- 输入：图像
- 输出：对比度增强后的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - method
     - 均衡方法（CLAHE/Histogram）
     - CLAHE

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择均衡方法。
3. 点击保存。

注意事项
--------

- 用于改善低对比度图像。
