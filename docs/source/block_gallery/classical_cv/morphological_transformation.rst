.. _形态变换:

形态变换
==================

简介
----

显示设置

输入 / 输出
-----------

- 输入：二值图像
- 输出：变换后的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - operation
     - 操作类型（erosion/dilation/opening/closing）
     - dilation
   * - kernel_size
     - 核大小
     - 5

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择操作类型和核大小。
3. 点击保存。

注意事项
--------

- 用于去噪、填充空洞等形态学处理。
