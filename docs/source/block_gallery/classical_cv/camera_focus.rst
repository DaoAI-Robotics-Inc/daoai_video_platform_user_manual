.. _相机对焦:

相机对焦
==================

简介
----

显示设置

输入 / 输出
-----------

- 输入：图像
- 输出：对焦质量评分

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - method
     - 评估方法（Laplacian/Variance）
     - Laplacian

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择评估方法。
3. 点击保存。

注意事项
--------

- 用于评估图像清晰度。
