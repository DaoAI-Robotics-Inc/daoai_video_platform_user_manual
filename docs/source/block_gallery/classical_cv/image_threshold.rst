.. _图像阈值:

图像阈值
==================

简介
----

显示设置

输入 / 输出
-----------

- 输入：图像
- 输出：二值化图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - threshold
     - 阈值（0~255）
     - 127
   * - method
     - 阈值方法（binary/otsu/adaptive）
     - binary

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置阈值和方法。
3. 点击保存。

注意事项
--------

- 用于图像分割和前景提取。
