.. _SIFT比较:

SIFT比较
==================

简介
----

比较多张图像的SIFT描述符

输入 / 输出
-----------

- 输入：多组SIFT特征
- 输出：相似度评分

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - match_threshold
     - 匹配阈值
     - 0.7

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置匹配阈值。
3. 点击保存。

注意事项
--------

- 用于图像相似度比较。
