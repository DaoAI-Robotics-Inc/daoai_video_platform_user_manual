图像灰度化
==================

简介
----

显示设置

输入 / 输出
-----------

- 输入：彩色图像
- 输出：灰度图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - method
     - 转换方法（weighted/average）
     - weighted

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择转换方法。
3. 点击保存。
