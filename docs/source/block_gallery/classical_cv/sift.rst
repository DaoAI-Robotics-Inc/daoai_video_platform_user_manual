.. _SIFT:

SIFT
==================

简介
----

显示设置

输入 / 输出
-----------

- 输入：图像
- 输出：SIFT特征描述符

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - nfeatures
     - 特征数量
     - 0（自动）

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置特征数量。
3. 点击保存。

注意事项
--------

- 用于图像匹配和目标识别。
