尺寸测量
==================

简介
----

测量对象相对于参考对象的尺寸

输入 / 输出
-----------

- 输入：检测结果 + 参考对象
- 输出：尺寸值

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - reference_size
     - 参考对象尺寸
     - 无
   * - unit
     - 单位（cm/mm/inch）
     - cm

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置参考对象尺寸和单位。
3. 点击保存。

注意事项
--------

- 需要已知尺寸的参考对象。
