.. _图像模糊:

图像模糊
==================

简介
----

显示设置

输入 / 输出
-----------

- 输入：图像
- 输出：模糊后的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - kernel_size
     - 核大小
     - 5
   * - method
     - 模糊方法（Gaussian/Median/Bilateral）
     - Gaussian

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置核大小和模糊方法。
3. 点击保存。

注意事项
--------

- 用于降噪或隐私保护。
