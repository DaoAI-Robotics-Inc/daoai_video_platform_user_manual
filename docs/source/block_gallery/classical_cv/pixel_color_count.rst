.. _像素颜色数:

像素颜色数
==================

简介
----

显示设置

输入 / 输出
-----------

- 输入：图像
- 输出：颜色统计

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - color_range
     - 颜色范围
     - 全部

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置颜色范围。
3. 点击保存。

注意事项
--------

- 用于颜色分布分析。
