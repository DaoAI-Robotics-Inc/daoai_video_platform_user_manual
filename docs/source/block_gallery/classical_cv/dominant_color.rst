.. _主色:

主色
==================

简介
----

获取图像的主导颜色（RGB格式）

输入 / 输出
-----------

- 输入：图像
- 输出：RGB颜色值

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - num_colors
     - 颜色数量
     - 1

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置要提取的颜色数量。
3. 点击保存。

注意事项
--------

- 基于K-means聚类算法。
