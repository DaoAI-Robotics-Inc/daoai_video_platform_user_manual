模板匹配
==================

简介
----

显示设置

输入 / 输出
-----------

- 输入：图像 + 模板图像
- 输出：匹配位置和置信度

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - method
     - 匹配方法（TM_CCOEFF/TM_CCORR）
     - TM_CCOEFF
   * - threshold
     - 匹配阈值
     - 0.8

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 上传模板图像并设置阈值。
3. 点击保存。

注意事项
--------

- 用于查找特定模式或对象。
