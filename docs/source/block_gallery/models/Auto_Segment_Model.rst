自动分割模型
==================

简介
----

在无需训练的情况下，对输入图像中的物体进行自动实例分割。

输入 / 输出
-----------

- 输入：视频帧 / 图像
- 输出：分割掩码（PNG / 多边形）

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - threshold
     - 置信度阈值（0~1）
     - 0.5

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择模型与参数，点击保存。

注意事项
--------

- 对高分辨率图像建议开启 GPU。
