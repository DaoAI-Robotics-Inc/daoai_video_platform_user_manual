LLM检测模型
==================

简介
----

运行基于大语言模型的物体检测模型，无需训练模型。

输入 / 输出
-----------

- 输入：视频帧 / 图像 + 文本描述
- 输出：检测框与类别

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - prompt
     - 检测任务的文本描述
     - 无
   * - confidence
     - 置信度阈值（0~1）
     - 0.3

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 输入检测任务的文本描述（例如："检测图像中的所有人员和车辆"）。
3. 调整置信度阈值，点击保存。

注意事项
--------

- 基于大语言模型，支持灵活的语义理解。
- 推理速度较传统模型慢，适合对准确度要求较高的场景。
