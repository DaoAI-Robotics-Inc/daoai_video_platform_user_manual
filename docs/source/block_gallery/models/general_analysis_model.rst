通用分析模型
============

简介
----

无需训练即可对检测到的物体进行属性分析/分类，适合快速搭建基于属性的筛选与分组场景。

输入/输出
--------

- 输入（Input）:
  - 图像 / 视频帧（来自上游节点或工作流输入）

- 输出（Output）:
  - 检测到的物体属性分类结果及置信度
  - 可选：Top-K 属性列表

配置参数详解
------------

.. list-table::
   :header-rows: 1
   :widths: 24 52 24

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 工作流中该节点的名称。
     - ``general_analysis_1``
   * - 备注
     - 可选备注信息，记录用途。
     - ``留空``
   * - 图像
     - 指定输入图像来源。
     - ``input.image``
   * - 属性标签
     - 需要分析/分类的属性列表，英文提示词，逗号分隔或 JSON 形式。
     - ``["color=red", "material=metal"]``
   * - 置信度阈值
     - 过滤低于阈值的预测结果。
     - ``0.3``
   * - Top-K
     - 返回置信度最高的前 K 个属性结果。
     - ``5``
