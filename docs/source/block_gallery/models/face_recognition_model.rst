人脸识别模型
============

简介
----

在图像中检测和识别人脸，并可基于已知人脸库进行身份匹配，适合门禁核验、考勤、访客登记等场景。

输入/输出
--------

- 输入（Input）:
  - 图像 / 视频帧（来自上游节点或工作流输入）

- 输出（Output）:
  - 人脸框位置及置信度
  - 人脸特征向量或匹配到的身份信息（如可用）
  - 推理是否成功、耗时

配置参数详解
------------

.. list-table::
   :header-rows: 1
   :widths: 24 52 24

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 工作流中该节点的名称。
     - ``face_recognition_1``
   * - 备注
     - 可选备注信息，记录用途。
     - ``留空``
   * - 图像
     - 指定输入图像来源。
     - ``input.image``
   * - 置信度阈值
     - 人脸检测的最小置信度，低于阈值的结果会被过滤。
     - ``0.5``
   * - 人脸库
     - 选择或配置用于比对的已知人脸库。
     - ``default_face_db``
   * - 特征模式
     - 输出特征向量或直接输出匹配身份。
     - ``embedding`` / ``match``
