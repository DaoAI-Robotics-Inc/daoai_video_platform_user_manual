Qwen3-VL-8B检测模型
==================

简介
----

运行Qwen3-VL-8B视觉语言模型进行物体检测。

输入 / 输出
-----------

- 输入：视频帧 / 图像 + 文本描述
- 输出：检测框与类别

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - prompt
     - 检测任务的文本描述
     - 无
   * - confidence
     - 置信度阈值（0~1）
     - 0.3

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 输入检测任务的文本描述。
3. 调整置信度阈值，点击保存。

注意事项
--------

- 基于 Qwen3-VL-8B 视觉语言模型。
- 模型较大，准确度较高，推理速度相对较慢。
