通用检测模型
==================

简介
----

运行物体检测模型，无需训练模型。

输入 / 输出
-----------

- 输入：视频帧 / 图像
- 输出：检测框与类别

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - classes
     - 要检测的类别（英文）
     - 无
   * - confidence
     - 置信度阈值（0~1）
     - 0.3

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 输入要检测的类别名称（英文，多个用逗号分隔）。
3. 调整置信度阈值，点击保存。

注意事项
--------

- 基于预训练的通用模型，支持语义检测。
