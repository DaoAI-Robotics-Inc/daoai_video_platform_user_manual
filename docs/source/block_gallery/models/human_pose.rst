人体姿态评估
============

简介
----

这是一个用于人体姿态评估的模型，可以检测人体的关键点，并给出人体姿态的评估结果。

输入/输出
--------

- 输入（Input）:
	- 图像 （来自上游节点或工作流输入）。

- 输出（Output）: 
	- 检测到的人体框位置和置信度
	- 对应关节、骨骼的颜色列表
	- 人体姿态的评估结果
    - 推理是否成功

.. note::
    该模型只检测人体框和返回人体关键点，想要在前端大屏显示出人体姿态，需要添加一个 :ref:`关键点可视化 <关键显示>` 模块。

配置参数详解
------------

.. list-table:: 
   :header-rows: 1

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 自定义该节点的名称，用于标识工作流中的该步骤。无需特意编辑，保持默认即可。
     - ``human_pose_estimation_1``
   * - 备注
     - 可选的备注信息，用于描述该步骤的用途。
     - ``留空``
   * - 图像
     - 指定输入图像的来源，可以是上游节点的输出或工作流的输入参数。
     - ``input image`` 
   * - 检测模式
     - 选择检测模式：wholebody（全身含手、脸、脚），body（仅身体），body_with_feet（身体含脚），hand（单手）。
     - ``wholebody``
   * - 置信度阈值
     - 人体检测的最小置信度阈值，范围为0到1。低于该阈值的检测结果将被过滤掉。
     - ``0.5``

使用场景
--------
- 需要对人体姿态进行评估。
- 需要对人体关键点进行检测。
- 需要让实时监控画面更加丰富
