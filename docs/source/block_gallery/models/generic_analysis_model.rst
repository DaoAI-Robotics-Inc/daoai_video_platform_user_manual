通用分析模型
==================

简介
----

对检测到的对象按属性进行自动分类，无需训练该模型。

输入 / 输出
-----------

- 输入：检测结果
- 输出：分类后的对象

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - attributes
     - 要分析的属性列表
     - 无

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 配置要分析的属性。
3. 点击保存。

注意事项
--------

- 模型已预训练，无需额外训练即可使用。
