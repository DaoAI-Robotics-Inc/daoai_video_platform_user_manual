通用实例分割模型
=================

简介
-------

这是一个用于通用实例分割的模型，可以对输入图像中的物体进行实例分割，并返回每个物体的边界框和分割掩码。

输入/输出
--------

- 输入（Input）:
	- 图像 （来自上游节点或工作流输入）。

- 输出（Output）: 
	- 所有实例分割结果
    - 推理是否成功
    - 推理耗时

.. note::
    该模型只检测物体框和返回物体分割掩码，想要在前端大屏显示出物体分割结果，需要添加一个 :ref:`遮罩显示 <遮罩显示>` 模块。

配置参数详解
--------------------

.. list-table:: 
   :header-rows: 1

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 自定义该节点的名称，用于标识工作流中的该步骤。无需特意编辑，保持默认即可。
     - ``general_instance_segmentation_1``
   * - 备注
     - 可选的备注信息，用于描述该步骤的用途。
     - ``留空``
   * - 图像
     - 指定输入图像的来源，可以是上游节点的输出或工作流的输入参数。
     - ``input image`` 
   * - 检测分类
     - 自定义检测类别的英文提示词，在 ``["  "]`` 中输入需要检测的物体类别，多个类别用逗号分隔。
     - **["person", "car", "bicycle"]**
   * - 置信度阈值
     - 设置检测结果的置信度阈值，范围为0到1。低于该阈值的检测结果将被过滤掉。
     - **0.3**
   * - 最大检测数量
     - 设置每张图像中最多检测出的物体数量，超过该数量的检测结果将被忽略。
     - **100**

使用场景
--------------------
- 需要对图像中的物体进行实例分割。
- 需要对图像中的物体进行分类。
- 需要收集图像中的物体信息。
