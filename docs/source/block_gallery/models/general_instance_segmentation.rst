通用实例分割模型
=================

简介
-------

无需训练的通用实例分割模型，对输入图像/视频帧中的物体进行分割，返回边界框与分割掩码。

输入/输出
--------

- 输入（Input）:
	- 图像 （来自上游节点或工作流输入）。

- 输出（Output）: 
	- 所有实例分割结果
    - 推理是否成功
    - 推理耗时

.. note::
  
    该模型只检测物体框和返回物体分割掩码，想要在前端大屏显示出物体分割结果，需要添加一个 :ref:`遮罩显示 <遮罩显示>` 模块。

配置参数详解
--------------------

.. list-table:: 
   :header-rows: 1
   :widths: 22 52 26

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 工作流中该节点的名称。
     - ``general_instance_segmentation_1``
   * - 备注
     - 可选的备注信息，用于描述该步骤的用途。
     - ``留空``
   * - 图像
     - 指定输入图像来源。
     - ``input.image`` 
   * - 检测分类
     - 需要检测的类别列表，英文提示词，建议用 JSON/数组形式填写。
     - ``["person", "car"]``
   * - 置信度阈值
     - 全局置信度阈值，范围 0~1。
     - ``0.3``
   * - 最大检测数量
     - 设置每张图像中最多检测出的物体数量，超过该数量的检测结果将被忽略。
     - ``100``

检测分类示例
------------

.. code-block:: json

   [
     "person",
     "car"
   ]
