检测共识
==================

简介
----

结合多个检测模型的预测结果以判断对象是否存在

输入 / 输出
-----------

- 输入：多组检测结果
- 输出：合并后的检测结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - min_consensus
     - 最小共识数量
     - 2
   * - iou_threshold
     - IOU 阈值
     - 0.5

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 配置最小共识数量和IOU阈值。
3. 点击保存。

注意事项
--------

- 用于提高检测可靠性，减少误报。
