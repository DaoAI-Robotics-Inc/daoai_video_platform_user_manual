限速器
==================

简介
----

限制工作流分支的运行速率

输入 / 输出
-----------

- 输入：任意数据流
- 输出：限速后的数据流

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - max_rate
     - 最大速率（次/秒）
     - 10
   * - burst_size
     - 突发大小
     - 1

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置最大速率和突发大小。
3. 点击保存。

注意事项
--------

- 用于控制下游模块的执行频率，避免过载。
