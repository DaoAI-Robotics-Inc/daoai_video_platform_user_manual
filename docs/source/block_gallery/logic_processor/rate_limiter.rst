.. _限速器:

限速器
==================

简介
----

限制工作流分支的运行速率（冷却时长），在指定时间间隔内只允许一次执行。

输入 / 输出
-----------

- 输入：任意数据流
- 输出：限速后的数据流

配置参数
--------

.. list-table::
   :header-rows: 1
   :widths: 24 52 24

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 工作流中该节点的名称。
     - ``rate_limiter_1``
   * - 备注
     - 可选备注信息，记录用途。
     - ``留空``
   * - 冷却时长
     - 允许执行之间的最短间隔时间（秒），范围 0~∞。
     - ``1.0``
   * - 依赖字段
     - 此区块之前的步骤/分支选择。
     - ``下拉选择上游节点``
   * - 下一步
     - 在速率限制允许的情况下执行的步骤。
     - ``下拉选择下游节点``
   * - 视频参考图像
     - 参考视频帧用于时间戳生成（仅节流时运行速度或帧率受限时可选）。
     - ``inputs.image`` 或留空
