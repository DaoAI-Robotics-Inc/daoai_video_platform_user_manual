继续执行
==================

简介
----

有条件地阻止分支的执行

输入 / 输出
-----------

- 输入：任意数据 + 条件表达式
- 输出：满足条件时继续执行

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - condition
     - 条件表达式
     - 无
   * - operator
     - 比较操作符（==, !=, >, <, >=, <=）
     - ==

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 配置条件表达式和比较操作符。
3. 点击保存。

注意事项
--------

- 常用于根据检测结果数量或置信度决定是否继续执行后续模块。
