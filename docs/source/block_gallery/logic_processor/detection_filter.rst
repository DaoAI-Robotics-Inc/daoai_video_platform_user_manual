检测过滤
==================

简介
----

有条件地过滤模型预测结果

输入 / 输出
-----------

- 输入：检测结果 + 过滤条件
- 输出：过滤后的检测结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - min_confidence
     - 最小置信度
     - 0.5
   * - classes_to_keep
     - 保留的类别
     - 全部
   * - min_area
     - 最小面积（像素）
     - 0

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 配置过滤条件（置信度、类别、面积等）。
3. 点击保存。

注意事项
--------

- 常用于去除低置信度或面积过小的检测框。
