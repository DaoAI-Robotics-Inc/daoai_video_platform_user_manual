检测过滤
==================

简介
----

检测过滤节点用于根据指定条件对检测结果进行筛选，保留符合条件的检测框，过滤掉不符合要求的检测结果。

该节点支持多种过滤维度，包括：

- **类别与置信度**：基于检测类别名称、属性名称或置信度进行过滤
- **检测尺寸**：基于检测框的宽度、高度或面积进行过滤
- **区域**：基于检测框与指定区域的位置关系进行过滤
- **父级检测**：基于父级检测框的存在性进行过滤

该节点常用于去除低置信度检测、筛选特定类别、过滤尺寸异常的检测框等场景，是工作流中重要的数据预处理节点。

输入 / 输出
-----------

- **输入**：
  
  - 检测结果（来自模型、区域内时间等节点的检测输出）
  - 过滤条件配置

- **输出**：
  
  - 过滤后的检测结果（符合条件的检测框集合）

配置参数概览
------------

   :header-rows: 1

参数详细说明
------------

**节点名称**

为该检测过滤节点指定唯一的标识符。

**备注**

可选的备注信息，用于记录该过滤节点的具体用途、过滤条件说明或注意事项。

**预测过滤**

选择要进行过滤的检测结果来源，主要来自：

- **模型节点**：如 ``detection_model.predictions``

**操作 - 配置检测过滤**

点击"配置检测过滤"按钮后，进入过滤条件配置页面。系统支持添加多个过滤条件，所有条件需同时满足（AND 逻辑）。

过滤条件配置详解
--------------

类别与置信度
~~~~~~~~~~~

基于对象类别与置信度过滤检测结果。

**过滤依据**：``类别与置信度``

**说明**：基于对象类别与置信度过滤检测结果

**配置参数**：

1. **过滤检测条件**
   
   选择要过滤的条件类型：

   - **按类别名称**
     
     - 根据检测对象的类别名称进行过滤
     - **比较操作符**：
       
       - ``包含``：检测类别包含指定的类别（支持多个，用逗号分隔）
       - 其他字符串比较操作符
     
     - **输入对象类别**：输入要过滤的类别名称，多个类别用逗号分隔
     - **提示**：输入对象类别，用逗号分隔
     - **示例**：``person,car,bicycle``

   - **按属性名称**
     
     - 根据检测框的自定义属性名称进行过滤
     - 比较操作符同字符串比较

   - **置信度**
     
     - 根据检测框的置信度分数进行过滤
     - **比较操作符**：
       
       - ``大于...`` （>=）
       - ``小于...`` （<=）
       - ``大于`` （>）
       - ``小于`` （<）
       - ``等于`` （==）
     
     - **输入数值**：输入置信度阈值（0-1之间的小数）
     - **示例**：``0.5``、``0.8``

检测尺寸
~~~~~~~

基于图像尺寸大小过滤检测结果。

**过滤依据**：``检测尺寸``

**说明**：基于图像尺寸大小对过滤检测结果

**配置参数**：

1. **图像**
   
   - 选择用于计算检测框尺寸的参考图像
   - 通常选择：``$inputs.image`` （工作流输入的原始图像）
   - 用途：确定检测框在图像中的相对尺寸

2. **如果检测尺寸为**
   
   - 选择尺寸比较的操作符和阈值
   - **比较操作符**：
     
     - ``小于...`` （<=）：检测框尺寸小于等于指定值
     - ``大于...`` （>=）：检测框尺寸大于等于指定值
     - ``小于`` （<）：检测框尺寸小于指定值
     - ``大于`` （>）：检测框尺寸大于指定值
     - ``等于`` （==）：检测框尺寸等于指定值
   
   - **输入数值**：输入尺寸阈值（具体含义取决于所选的尺寸类型）
   - **示例**：``5``、``100``

区域
~~~~

基于特定区域过滤检测结果。

**过滤依据**：``区域``

**说明**：基于特定区域过滤检测结果

**配置参数**：

1. **检测位置**
   
   - 选择检测框与区域的位置关系判断方式
   - 可选值：
     
     - ``在``：检测框在指定区域内
     - ``不在``：检测框不在指定区域内

2. **检测参考点**
   
   - 选择用于判断位置关系的检测框参考点
   - 可选值：
     
     - ``中心``：使用检测框的中心点进行判断
     - ``左上``：使用检测框的左上角进行判断
     - ``右上``：使用检测框的右上角进行判断
     - ``左下``：使用检测框的左下角进行判断
     - ``右下``：使用检测框的右下角进行判断

3. **区域定义**
   
   - 选择要用于过滤的区域
   - 可选值：
     
     - ``在编辑器中定义``：在工作流编辑器中定义新的多边形区域
     -  ``手动输入``：手动输入区域坐标

4. **设置多边形区域**
   
   - 点击橙色按钮"设置多边形区域"
   - 在可视化编辑器中绘制或调整区域多边形

父级检测
~~~~~~~

基于父级边界框类别过滤检测结果。

**过滤依据**：``父级检测``

**说明**：基于父级边界框类别过滤检测结果（用于处理嵌套检测的场景）

**配置参数**：

1. **父级类别名称**
   
   - 输入要匹配的父级检测框的类别名称
   - **输入框提示**：输入父级类别名称
   - **用途**：只保留父级检测框类别符合条件的子检测框
   - **示例**：
     
     - 输入 ``person``：只保留父级为"person"检测框内的子检测
     - 输入空值：筛选没有父级的顶级检测框

**典型应用场景**：

- 在人脸检测中，先检测人体（父级），再在人体区域内检测人脸（子级）
- 过滤出特定父级类别下的子对象
- 区分顶级检测和嵌套检测
