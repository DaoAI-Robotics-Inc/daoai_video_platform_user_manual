.. _Delta滤波器:

Delta滤波器
==================

简介
----

显示设置

输入 / 输出
-----------

- 输入：数值序列
- 输出：变化超过阈值的数值

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - threshold
     - 变化阈值
     - 0.1

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置变化阈值。
3. 点击保存。

注意事项
--------

- 用于过滤数值波动，仅在变化显著时触发。
