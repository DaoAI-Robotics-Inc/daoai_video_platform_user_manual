拼图图像
==================

简介
----

通过共同路径拼接两个图像

输入 / 输出
-----------

- 输入：两张图像
- 输出：拼接后的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - direction
     - 拼接方向（horizontal/vertical）
     - horizontal

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择拼接方向。
3. 点击保存。

注意事项
--------

- 用于全景拼接或多视角合成。
