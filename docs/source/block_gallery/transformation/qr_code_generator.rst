二维码生成器
==================

简介
----

从文本输入生成二维码图像

输入 / 输出
-----------

- 输入：文本字符串
- 输出：二维码图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - size
     - 图像大小（像素）
     - 256
   * - error_correction
     - 纠错级别（L/M/Q/H）
     - M

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 输入要编码的文本。
3. 设置大小和纠错级别，点击保存。

注意事项
--------

- 支持多种纠错级别和尺寸。
