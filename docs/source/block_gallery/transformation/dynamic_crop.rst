动态裁剪
==================

简介
----

使用检测模型的边界框裁剪图像

输入 / 输出
-----------

- 输入：图像 + 检测结果
- 输出：裁剪后的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - padding
     - 边距（像素）
     - 10

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置边距。
3. 点击保存。

注意事项
--------

- 根据检测框动态裁剪，适用于目标提取。
