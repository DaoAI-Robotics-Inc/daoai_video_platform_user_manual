动态裁剪
==================

简介
----

使用检测模型的边界框裁剪图像。

输入 / 输出
-----------

- 输入：图像 + 检测结果
- 输出：裁剪后的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 52 24

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 工作流中该节点的名称。
     - ``dynamic_crop_1``
   * - 备注
     - 可选备注信息，记录用途。
     - ``留空``
   * - 图像裁剪
     - 输入图像来源。
     - ``input.image``
   * - 感兴趣区域
     - 检测模型输出包含用于裁剪的边界框。
     - 选择上游检测输出
   * - 遮罩透明度
     - 在实例分割时，可使用遮罩透明度来控制背景去除。0.1~1。
     - ``0``
   * - 背景颜色
     - 在分割后填充的背景颜色，十六进制或 RGB/HSV。默认透明。
     - ``0,0,0`` (或留空代表透明)
