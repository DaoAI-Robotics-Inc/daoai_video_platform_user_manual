绝对静态裁剪
==================

简介
----

按固定座标裁剪图像

输入 / 输出
-----------

- 输入：图像
- 输出：裁剪后的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - x1, y1
     - 左上角坐标（像素）
     - 0, 0
   * - x2, y2
     - 右下角坐标（像素）
     - 100, 100

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置裁剪区域坐标。
3. 点击保存。

注意事项
--------

- 使用固定像素坐标，不随图像尺寸变化。
