静态物体检测
==================

简介
----

从用户自定义的边界框创建静态物体检测结果，可用于固定区域的目标标注或占用检测。

输入 / 输出
-----------

- 输入：图像 + 自定义边界框
- 输出：带静态检测结果的图像/检测数据

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 52 24

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 工作流中该节点的名称。
     - ``static_object_detection_1``
   * - 备注
     - 可选备注信息，记录用途。
     - ``留空``
   * - 输入图像
     - 用于附加检测结果的图像。
     - ``input.image``
   * - 检测框
     - 边界框及其标签和置信度的列表。
     - 点击绘制边界框配置区域和标签
