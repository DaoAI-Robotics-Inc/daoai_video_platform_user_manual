检测偏移
==================

简介
----

在检测到的对象宽度和高度周围添加填充

输入 / 输出
-----------

- 输入：检测结果
- 输出：扩展后的检测框

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - offset_x
     - 水平偏移（像素）
     - 10
   * - offset_y
     - 垂直偏移（像素）
     - 10

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置水平和垂直偏移量。
3. 点击保存。

注意事项
--------

- 用于扩大检测框以包含更多上下文。
