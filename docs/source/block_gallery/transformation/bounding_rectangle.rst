边界框
==================

简介
----

找到检测的多边形周围的最小包围框

输入 / 输出
-----------

- 输入：多边形坐标
- 输出：矩形边界框

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - padding
     - 边距（像素）
     - 0

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置边距（可选）。
3. 点击保存。

注意事项
--------

- 将不规则多边形转换为矩形边界框。
