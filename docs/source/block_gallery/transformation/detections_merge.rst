检测合并多个
==================

简介
----

将多个检测结果合并为一个边界框

输入 / 输出
-----------

- 输入：多组检测结果
- 输出：合并后的边界框

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - iou_threshold
     - IOU阈值
     - 0.5

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置IOU阈值。
3. 点击保存。

注意事项
--------

- 将重叠的检测框合并为一个。
