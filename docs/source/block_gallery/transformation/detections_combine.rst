检测合并
==================

简介
----

将两个预测集合并为一个预测

输入 / 输出
-----------

- 输入：两组检测结果
- 输出：合并后的检测结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - merge_strategy
     - 合并策略（union/intersection）
     - union

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择合并策略。
3. 点击保存。

注意事项
--------

- 用于合并多个模型的检测结果。
