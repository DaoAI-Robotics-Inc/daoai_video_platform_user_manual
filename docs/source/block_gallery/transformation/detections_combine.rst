.. _检测结果组合:

检测结果组合
==================

简介
----

将两个预测集合并为一个预测集。

输入 / 输出
-----------

- 输入：两组检测结果
- 输出：合并后的检测结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 工作流中该节点的名称。
     - ``detections_combine_1``
   * - 备注
     - 可选备注信息，记录用途。
     - ``留空``
   * - 第一组预测
     - 第一组检测/预测结果。
     - 下拉菜单选择上游输出
   * - 第二组预测
     - 第二组检测/预测结果。
     - 下拉菜单选择上游输出
