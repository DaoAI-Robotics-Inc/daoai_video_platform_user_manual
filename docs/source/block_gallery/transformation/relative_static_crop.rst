相对静态裁剪
==================

简介
----

按比例（%）裁剪图像尺寸

输入 / 输出
-----------

- 输入：图像
- 输出：裁剪后的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - left
     - 左侧裁剪比例（0~1）
     - 0.1
   * - right
     - 右侧裁剪比例（0~1）
     - 0.9
   * - top
     - 顶部裁剪比例（0~1）
     - 0.1
   * - bottom
     - 底部裁剪比例（0~1）
     - 0.9

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置裁剪比例。
3. 点击保存。

注意事项
--------

- 使用相对比例，适应不同尺寸的图像。
