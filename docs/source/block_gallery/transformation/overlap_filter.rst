.. _重叠过滤:

重叠过滤
==================

简介
----

过滤与其他类叠加的对象

输入 / 输出
-----------

- 输入：检测结果
- 输出：过滤后的检测结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - overlap_threshold
     - 重叠阈值（0~1）
     - 0.5

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置重叠阈值。
3. 点击保存。

注意事项
--------

- 用于去除高度重叠的冗余检测。
