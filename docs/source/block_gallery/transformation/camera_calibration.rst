相机标定
==================

简介
----

使用校准从图像中去除桶形机头变

输入 / 输出
-----------

- 输入：图像 + 标定参数
- 输出：矫正后的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - calibration_file
     - 标定文件路径
     - 无

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 上传相机标定文件。
3. 点击保存。

注意事项
--------

- 需要预先完成相机标定。
