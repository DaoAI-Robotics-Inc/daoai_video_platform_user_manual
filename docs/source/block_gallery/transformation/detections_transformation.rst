检测变换
==================

简介
----

对检测到的边界框应用变换

输入 / 输出
-----------

- 输入：检测结果 + 变换矩阵
- 输出：变换后的检测结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - transformation_type
     - 变换类型（平移/旋转/缩放）
     - 平移

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择变换类型并设置参数。
3. 点击保存。

注意事项
--------

- 用于坐标系转换或视角变换。
