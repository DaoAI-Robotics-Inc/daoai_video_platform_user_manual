高速公路追踪器
==================

简介
----

使用为高速公路优化的 ByteTrack 跟踪并更新视频帧中的对象位置

输入 / 输出
-----------

- 输入：视频帧 + 检测结果
- 输出：跟踪结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - track_thresh
     - 跟踪阈值
     - 0.6
   * - match_thresh
     - 匹配阈值
     - 0.85

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整跟踪参数。
3. 点击保存。

注意事项
--------

- 针对高速场景优化，能更好处理快速移动对象。
