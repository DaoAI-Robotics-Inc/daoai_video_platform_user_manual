区域外停留时间
==================

简介
----

追踪对象在指定区域外停留的时间，包括滞留天时间

输入 / 输出
-----------

- 输入：跟踪结果 + 区域坐标
- 输出：停留时长

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - zone_coordinates
     - 区域坐标
     - 无
   * - min_time
     - 最小时长（秒）
     - 10

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 绘制监控区域。
3. 设置最小时长，点击保存。

注意事项
--------

- 用于检测违规停留或异常行为。
