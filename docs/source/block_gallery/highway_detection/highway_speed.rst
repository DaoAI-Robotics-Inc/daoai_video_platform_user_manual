高速公路测速
==================

简介
----

使用相机标定计算高速公路上跟踪对象的精确速度

输入 / 输出
-----------

- 输入：跟踪结果 + 标定参数
- 输出：速度值（km/h）

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - calibration_file
     - 标定文件
     - 无
   * - smoothing
     - 是否平滑
     - true

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 上传相机标定文件。
3. 点击保存。

注意事项
--------

- 需要准确的相机标定以获得精确速度。
