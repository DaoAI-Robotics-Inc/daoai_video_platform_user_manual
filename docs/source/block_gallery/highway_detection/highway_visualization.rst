.. _Highway Visualization:

Highway Visualization
==================

简介
----

Highway Visualization

输入 / 输出
-----------

- 输入：跟踪结果 + 统计信息
- 输出：可视化图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - show_speed
     - 是否显示速度
     - true
   * - show_count
     - 是否显示计数
     - true

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 配置显示选项。
3. 点击保存。

注意事项
--------

- 用于展示高速公路监控统计信息。
