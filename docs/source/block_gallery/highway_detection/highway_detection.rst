高速检测
==================

简介
----

对高速视频进行车辆计数、平均速度计算、车道速度计算以及车速计算以处理预测问隔帧的算法。

输入 / 输出
-----------

- 输入：视频帧 + 检测结果
- 输出：统计信息

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - lanes
     - 车道数量
     - 3
   * - frame_skip
     - 跳帧间隔
     - 2

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 配置车道数量和跳帧间隔。
3. 点击保存。

注意事项
--------

- 专门针对高速公路场景优化。
