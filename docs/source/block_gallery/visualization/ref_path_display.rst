参考路径显示
==================

简介
----

在图像中绘制参考路径

输入 / 输出
-----------

- 输入：图像 + 路径坐标
- 输出：带路径标记的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - thickness
     - 路径线粗细（像素）
     - 3
   * - color
     - 路径颜色（RGB）
     - (255, 255, 0)

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整路径线粗细和颜色。
3. 点击保存。

注意事项
--------

- 用于显示预设的运动轨迹或路线。
