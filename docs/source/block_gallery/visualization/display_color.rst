显示颜色
==================

简介
----

在图像中，用选择覆盖所有检测到的区域以外的区域

输入 / 输出
-----------

- 输入：图像 + 检测结果
- 输出：处理后的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - color
     - 覆盖颜色（RGB）
     - (0, 0, 0)
   * - opacity
     - 不透明度（0~1）
     - 0.5

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择覆盖颜色和不透明度。
3. 点击保存。

注意事项
--------

- 用于突出显示检测区域，遮蔽其他区域。
