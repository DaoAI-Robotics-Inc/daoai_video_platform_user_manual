.. _点显示:

点显示
==================

简介
----

根据提供的检测结果，在图像的特定坐标标位置绘制点

输入 / 输出
-----------

- 输入：图像 + 坐标点
- 输出：带点标记的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - radius
     - 点半径（像素）
     - 5
   * - color
     - 点颜色（RGB）
     - (255, 0, 0)

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整点半径和颜色。
3. 点击保存。

注意事项
--------

- 适用于标记关键点或中心点。
