仪表板可视化
==================

简介
----

仪表板可视化节点用于将带有预测可视化效果的图像输出到 **实时警报仪表板**，实现实时监控和展示。

该节点是可视化流程的终端节点，将经过各种可视化处理后的图像推送到平台的 **实时警报仪表板** 界面，供用户实时查看检测、分类等模型的运行结果。

输入 / 输出
-----------

- **输入**：
  
  - 图像（通常是经过可视化处理的图像）

- **输出**：
  
  - 将图像推送到流式仪表板显示

配置参数详解
------------

.. list-table::
   :header-rows: 1
   :widths: 20 50 30

   * - 参数名称
     - 说明
     - 示例/默认值
   * - **节点名称**
     - 步骤名称，用于标识该节点的唯一标识符
     - ``dashboard_visualization_1``
   * - **备注**
     - 可选的备注信息，用于描述该步骤的用途
     - 留空
   * - **输入图像**
     - 指定要显示在仪表板上的图像，通常是上游可视化节点的输出
     - ``下拉菜单选择``
