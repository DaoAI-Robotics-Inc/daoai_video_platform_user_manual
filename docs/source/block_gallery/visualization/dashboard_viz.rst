仪表板可视化
==================

简介
----

对预测结果进行可视化，可用于在仪表板显示。

输入 / 输出
-----------

- 输入：图像 + 检测/分类结果
- 输出：格式化的可视化数据

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - format
     - 输出格式
     - JSON
   * - include_image
     - 是否包含图像
     - true

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择输出格式。
3. 点击保存。

注意事项
--------

- 专为仪表板集成设计，输出结构化数据。
