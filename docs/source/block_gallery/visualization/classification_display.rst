分类显示
==================

简介
----

可视化单标签或多标签分类结果，并支持自定义显示选项

输入 / 输出
-----------

- 输入：图像 + 分类结果
- 输出：带分类标签的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - position
     - 标签位置
     - top-left
   * - font_size
     - 字体大小
     - 16

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择标签位置和字体大小。
3. 点击保存。

注意事项
--------

- 支持多标签分类结果的同时显示。
