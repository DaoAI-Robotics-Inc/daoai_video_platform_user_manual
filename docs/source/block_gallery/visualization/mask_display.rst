遮罩显示
==================

简介
----

在图像中检测到的对象上应用遮罩

输入 / 输出
-----------

- 输入：图像 + 分割掩码
- 输出：带遮罩的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - opacity
     - 遮罩不透明度（0~1）
     - 0.5
   * - color
     - 遮罩颜色（RGB）
     - (0, 255, 0)

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整遮罩不透明度和颜色。
3. 点击保存。

注意事项
--------

- 用于显示实例分割或语义分割结果。
