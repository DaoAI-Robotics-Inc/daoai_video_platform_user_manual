文本可视化
==========

简介
----

在图像上叠加文本，支持静态文本、模板占位符和条件格式化，可用于状态提示、调试信息或结果标注。

输入/输出
--------

- 输入（Input）:
  - 图像（来自上游节点或工作流输入）

- 输出（Output）:
  - 叠加文本后的图像

配置参数详解
------------

.. list-table::
   :header-rows: 1
   :widths: 24 52 24

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 工作流中该节点的名称。
     - ``text_visualization_1``
   * - 备注
     - 可选备注信息，记录用途。
     - ``留空``
   * - 输入图像
     - 用于可视化的图像来源。
     - ``input.image``
   * - 复制图像
     - 是否先复制输入图像再进行可视化，保留原始帧。
     - ``True``
   * - 文本模式
     - 文本来源模式，支持 ``Static Text``（静态文本）或模板驱动。
     - ``Static Text``
   * - 文本内容
     - 静态文本内容或绑定字段的占位符。
     - ``Hello World``
   * - 模板
     - 含占位符的模板字符串（如带 {key} 的格式）。
     - ``Status: {process_status}\nProgress: {progress}%``
   * - 模板数据
     - 模板替换用的数据（JSON），可选。
     - ``{"process_status": "running", "progress": 75}``
   * - 文本位置
     - 文本在图像上的位置，支持 ``TOP_LEFT``/``TOP_RIGHT``/``BOTTOM_LEFT``/``BOTTOM_RIGHT`` 等。
     - ``TOP_LEFT``
   * - 区域
     - 可选多边形区域用于相对定位或裁剪，JSON 数组形式。
     - ``[[0,0,0],[100,0,0],[0,100,100]]``
   * - 文本大小
     - 文本字号或缩放因子。
     - ``1``
   * - 文本粗细
     - 文本绘制粗细。
     - ``2``
   * - 文本内边距
     - 文本周围填充的像素数。
     - ``10``
   * - 边框圆角
     - 标签背景的边框圆角像素。
     - ``5``
   * - 文本颜色
     - 文本颜色。
     - ``WHITE``
   * - 背景颜色
     - 文本背景颜色。
     - ``BLACK``
