椭圆显示
==================

简介
----

在图像中检测到的对象周围绘制椭圆

输入 / 输出
-----------

- 输入：图像 + 检测结果
- 输出：带椭圆标记的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - color
     - 椭圆颜色（RGB）
     - (0, 255, 255)
   * - thickness
     - 线条粗细
     - 2

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择椭圆颜色和线条粗细。
3. 点击保存。

注意事项
--------

- 根据检测框自动计算椭圆参数。
