多边形区域显示
==================

简介
----

在图像中多边形区域上应用遮罩或绘制轮廓，可用于标记 ROI/禁区或叠加热力/遮罩效果。

输入 / 输出
-----------

- 输入：图像 + 多边形区域列表
- 输出：叠加多边形区域（填充或轮廓）的图像

配置参数
--------

.. list-table::
   :header-rows: 1
   :widths: 24 52 24

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 工作流中该节点的名称。
     - ``polygon_zone_visualization_1``
   * - 备注
     - 可选备注信息，记录用途。
     - ``留空``
   * - 输入图像
     - 用于可视化的图像来源。
     - ``input.image``
   * - 复制图像
     - 是否先复制输入图像再进行可视化，保留原始帧。
     - ``True``
   * - 区域形状
     - 多边形区域（每个挨个一个）以 ``[[x1,y1], [x2,y2], [x3,y3], ...]`` 表示，每个区域需至少 3 个点。
     - ``点击配置多边形区域``
   * - 多边形颜色
     - 区域颜色（HEX）。
     - ``#5bb573``
   * - 透明度
     - 遮罩叠加层的透明度（0~1）。
     - ``0.3``
   * - 绘制轮廓
     - 将区域绘制为轮廓而不是填充遮罩。
     - ``False``
   * - 轮廓粗细
     - 轮廓的粗细（仅在绘制轮廓为 True 时生效）。
     - ``2``
