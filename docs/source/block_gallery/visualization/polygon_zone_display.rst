多边形区域显示
==================

简介
----

在图像中多边形区域上应用遮罩

输入 / 输出
-----------

- 输入：图像 + 多边形区域
- 输出：带区域遮罩的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - fill_opacity
     - 填充不透明度（0~1）
     - 0.3
   * - border_thickness
     - 边界线粗细
     - 2

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整填充不透明度和边界线粗细。
3. 点击保存。

注意事项
--------

- 用于标记感兴趣区域（ROI）或禁区。
