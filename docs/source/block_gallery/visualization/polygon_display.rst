多边形显示
==================

简介
----

在图像中检测到的对象周围绘制多边形

输入 / 输出
-----------

- 输入：图像 + 多边形坐标
- 输出：带多边形标记的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - thickness
     - 线条粗细（像素）
     - 2
   * - color
     - 多边形颜色（RGB）
     - (255, 0, 255)

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整线条粗细和颜色。
3. 点击保存。

注意事项
--------

- 适用于不规则形状的对象标注。
