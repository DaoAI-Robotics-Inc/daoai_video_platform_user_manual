三角显示
==================

简介
----

在图像中根据提供的检测结果，在特定坐标标位置绘制三角形标记

输入 / 输出
-----------

- 输入：图像 + 坐标点
- 输出：带三角形标记的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - size
     - 三角形大小（像素）
     - 15
   * - color
     - 三角形颜色（RGB）
     - (255, 128, 0)
   * - thickness
     - 线条粗细
     - 2

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整三角形大小、颜色和线条粗细。
3. 点击保存。

注意事项
--------

- 适用于方向指示或特殊标记。
