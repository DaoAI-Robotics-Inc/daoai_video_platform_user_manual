圆形显示
==================

简介
----

在图像中检测到的对象周围绘制圆形

输入 / 输出
-----------

- 输入：图像 + 检测结果
- 输出：带圆形标记的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - radius
     - 圆形半径（像素）
     - 20
   * - color
     - 圆形颜色（RGB）
     - (255, 0, 0)
   * - thickness
     - 线条粗细（像素）
     - 2

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整圆形半径、颜色和线条粗细。
3. 点击保存。

注意事项
--------

- 适用于标记点状目标或关键点。
