关键显示
==================

简介
----

在图像中检测到的对象上绘制关键支链

输入 / 输出
-----------

- 输入：图像 + 关键点检测结果
- 输出：带关键点标记的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - point_radius
     - 关键点半径（像素）
     - 3
   * - line_thickness
     - 连接线粗细
     - 2

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整关键点半径和连接线粗细。
3. 点击保存。

注意事项
--------

- 适用于人体姿态估计、骨骼关键点等场景。
