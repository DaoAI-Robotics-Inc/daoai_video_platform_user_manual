颜色显示
==================

简介
----

在图像中检测到的对象上绘制颜色

输入 / 输出
-----------

- 输入：图像 + 检测结果
- 输出：带颜色标记的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - color_map
     - 类别-颜色映射
     - 自动
   * - opacity
     - 不透明度（0~1）
     - 0.3

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 配置颜色映射和不透明度。
3. 点击保存。

注意事项
--------

- 可为不同类别配置不同颜色。
