轨迹显示
==================

简介
----

根据检测跟踪结果绘制轨迹

输入 / 输出
-----------

- 输入：图像 + 跟踪结果
- 输出：带轨迹的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - trace_length
     - 轨迹长度（帧数）
     - 30
   * - thickness
     - 轨迹线粗细
     - 2
   * - color
     - 轨迹颜色（RGB）
     - (0, 255, 255)

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整轨迹长度、线粗细和颜色。
3. 点击保存。

注意事项
--------

- 需配合跟踪模块使用。
