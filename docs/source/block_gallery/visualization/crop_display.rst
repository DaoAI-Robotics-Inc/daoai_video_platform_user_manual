裁剪显示
==================

简介
----

在场景中绘制放大后的检测作物

输入 / 输出
-----------

- 输入：图像 + 检测结果
- 输出：带裁剪预览的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - scale
     - 放大倍数
     - 2.0
   * - position
     - 预览位置
     - top-right

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整放大倍数和预览位置。
3. 点击保存。

注意事项
--------

- 用于在原图上显示检测区域的放大预览。
