像素显示
==================

简介
----

在图像中检测到的对象进行像素化处理

输入 / 输出
-----------

- 输入：图像 + 检测结果
- 输出：像素化处理后的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - pixel_size
     - 像素块大小
     - 10

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整像素块大小。
3. 点击保存。

注意事项
--------

- 常用于隐私保护，如人脸像素化。
