显示光环
==================

简介
----

在图像中检测到的对象周围绘制光晕

输入 / 输出
-----------

- 输入：图像 + 检测结果
- 输出：带光晕效果的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - halo_size
     - 光晕大小（像素）
     - 15
   * - color
     - 光晕颜色（RGB）
     - (255, 255, 0)
   * - opacity
     - 不透明度（0~1）
     - 0.4

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整光晕大小、颜色和不透明度。
3. 点击保存。

注意事项
--------

- 光晕效果可增强视觉效果，突出重点对象。
