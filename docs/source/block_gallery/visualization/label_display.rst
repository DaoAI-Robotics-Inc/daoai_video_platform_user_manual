标签显示
==================

简介
----

根据提供的检测结果，在图像的特定坐标标位置绘制标签

输入 / 输出
-----------

- 输入：图像 + 检测结果
- 输出：带文本标签的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - font_size
     - 字体大小
     - 14
   * - bg_color
     - 背景颜色（RGB）
     - (255, 255, 255)
   * - text_color
     - 文本颜色（RGB）
     - (0, 0, 0)

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整字体大小和颜色。
3. 点击保存。

注意事项
--------

- 可显示类别名称、置信度等信息。
