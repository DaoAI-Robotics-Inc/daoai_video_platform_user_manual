背景颜色
==================

简介
----

背景颜色模块用于在图像中用指定颜色覆盖所有检测到的区域**以外**的区域，从而突出显示检测目标。该模块可以帮助用户聚焦关注检测到的对象，隐藏背景干扰信息。

效果展示：
  .. image:: ../images/visualization/background.png
    :alt: Background Color Visualization Example
    :align: center
    :width: 80%

输入 / 输出
-----------

- **输入**：图像 + 预测结果（检测框/分割掩码等）
- **输出**：处理后的可视化图像

配置参数详解
------------

.. list-table::
   :header-rows: 1
   :widths: 20 50 30

   * - 参数名称
     - 说明
     - 示例/默认值
   * - **节点名称**
     - 步骤名称，用于标识该节点的唯一标识符
     - ``background_color_visualization_1``
   * - **备注**
     - 可选的备注信息，用于描述该步骤的用途
     - 留空
   * - **输入图像**
     - 指定输入图像的来源，可以是上游节点的输出或工作流的输入参数
     - ``input.image``
   * - **复制图像**
     - 启用此选项以创建输入图像的副本并可视化，保留原始图像。在叠加多个可视化节点时有用。
     - ``True``
   * - **预测显示**
     - 提供预测显示结果，指定上游预测节点的输出
     - ``daoai_world_model_1.predictions``
   * - **背景颜色**
     - 设置背景覆盖的颜色，可选值包括常见颜色名称或RGB值
     - ``BLACK``
   * - **透明度**
     - 设置背景覆盖的透明度（0~1之间），0为完全透明，1为完全不透明
     - ``0.5``
