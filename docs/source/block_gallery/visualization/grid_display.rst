网格显示
==================

简介
----

以网格形式显示图像数组

输入 / 输出
-----------

- 输入：多张图像
- 输出：网格排列的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - columns
     - 列数
     - 3
   * - spacing
     - 图像间距（像素）
     - 10

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置网格列数和间距。
3. 点击保存。

注意事项
--------

- 用于批量显示多个图像结果。
