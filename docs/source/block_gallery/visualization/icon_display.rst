图标显示
==================

简介
----

在图像中根据检测结果或成或特定静态标位置绘制图标

输入 / 输出
-----------

- 输入：图像 + 检测结果 + 图标
- 输出：带图标的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - icon_path
     - 图标文件路径
     - 无
   * - size
     - 图标大小（像素）
     - 32

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 上传或选择图标文件。
3. 调整图标大小，点击保存。

注意事项
--------

- 支持 PNG 格式透明图标。
