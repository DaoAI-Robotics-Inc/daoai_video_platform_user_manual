模糊显示
==================

简介
----

在图像中检测到的对象运行模糊处理

输入 / 输出
-----------

- 输入：图像 + 检测结果
- 输出：模糊处理后的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - blur_strength
     - 模糊强度（1~100）
     - 15

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整模糊强度。
3. 点击保存。

注意事项
--------

- 常用于隐私保护，如人脸模糊、车牌模糊等。
