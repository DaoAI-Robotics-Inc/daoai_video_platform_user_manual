模糊显示
==================

简介
----

模糊显示模块用于对图像中检测到的对象进行模糊处理。该模块常用于隐私保护场景，如人脸模糊、车牌模糊等，通过对检测区域应用模糊效果来隐藏敏感信息。

效果展示：
  .. image:: ../images/visualization/blur.png
    :alt: Blur Visualization Example
    :align: center
    :width: 80%
    
输入 / 输出
-----------

- **输入**：图像 + 预测结果（检测框/分割掩码等）
- **输出**：模糊处理后的可视化图像

配置参数详解
------------

.. list-table::
   :header-rows: 1
   :widths: 20 50 30

   * - 参数名称
     - 说明
     - 示例/默认值
   * - **节点名称**
     - 步骤名称，用于标识该节点的唯一标识符
     - ``blur_visualization_1``
   * - **备注**
     - 可选的备注信息，用于描述该步骤的用途
     - 留空
   * - **输入图像**
     - 指定输入图像的来源，可以是上游节点的输出或工作流的输入参数
     - ``input.image``
   * - **复制图像**
     - 启用此选项以创建输入图像的副本并可视化，保留原始图像。在叠加多个可视化节点时有用。
     - ``True``
   * - **预测显示**
     - 提供预测显示结果，指定上游预测节点的输出
     - ``model.predictions``
   * - **模糊核大小**
     - 用于模糊的平均池化核大小，值越大模糊效果越强
     - ``15``
