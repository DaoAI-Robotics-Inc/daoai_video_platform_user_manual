角显示
==================

简介
----

在图像中检测到的对象的角绘制矩形

输入 / 输出
-----------

- 输入：图像 + 检测结果
- 输出：带角标记的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - corner_length
     - 角长度（像素）
     - 20
   * - thickness
     - 线条粗细
     - 2

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整角长度和线条粗细。
3. 点击保存。

注意事项
--------

- 仅标记矩形的四个角，比完整边界框更简洁。
