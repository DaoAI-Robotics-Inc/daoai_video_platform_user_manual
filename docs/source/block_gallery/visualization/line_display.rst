线条计数显示
======================================

简介
----

在图像/视频上绘制计数线，统计目标穿过线段的次数，可用于越界/流量统计场景。

输入 / 输出
-----------

- 输入：图像 + 线段坐标
- 输出：叠加计数线和文本后的图像，以及计数结果

配置参数
--------

.. list-table::
   :header-rows: 1
   :widths: 24 52 24

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 工作流中该节点的名称。
     - ``line_counter_visualization_1``
   * - 备注
     - 可选备注信息，记录用途。
     - ``留空``
   * - 输入图像
     - 用于可视化的图像来源。
     - ``input.image``
   * - 复制图像
     - 是否先复制输入图像再进行可视化，保留原始帧。
     - ``True``
   * - 线条坐标
     - 由两点坐标定义的线段列表，形如 ``[[x1, y1], [x2, y2]]``。
     - ``[[0,0],[50,50],[100,100]]``
   * - 线条颜色
     - 线段/区域颜色（HEX）。
     - ``#5bb573``
   * - 线条粗细
     - 线条宽度（像素）。
     - ``2``
   * - 文本粗细
     - 计数字体粗细（像素）。
     - ``1``
   * - 文本大小
     - 计数字体大小（像素）。
     - ``1``
   * - 计数
     - 参考进入线区域的对象数量（输入/绑定字段）。
     - 例如绑定检测结果的计数字段
   * - 计数输出
     - 参考穿过线区域的对象数量（输入/绑定字段）。
     - 例如绑定累计通过数
   * - 透明度
     - 覆盖叠加层的透明度（0~1）。
     - ``0.3``
