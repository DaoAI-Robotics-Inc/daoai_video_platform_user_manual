线条显示
==================

简介
----

在图像中的线条区域上应用遮罩

输入 / 输出
-----------

- 输入：图像 + 线条坐标
- 输出：带线条标记的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - thickness
     - 线条粗细（像素）
     - 3
   * - color
     - 线条颜色（RGB）
     - (0, 0, 255)

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整线条粗细和颜色。
3. 点击保存。

注意事项
--------

- 常用于绘制检测线、越界线等。
