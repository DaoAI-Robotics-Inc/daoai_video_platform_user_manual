边界框显示
==================

简介
----

在图像中检测到的对象周围绘制矩形

输入 / 输出
-----------

- 输入：图像 + 检测结果
- 输出：带边界框的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - thickness
     - 线条粗细（像素）
     - 2
   * - color
     - 边界框颜色（RGB）
     - (0, 255, 0)

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择线条粗细和颜色。
3. 点击保存。

注意事项
--------

- 最常用的可视化方式，用于显示检测结果。
