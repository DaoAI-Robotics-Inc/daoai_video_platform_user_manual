透视校正
==================

简介
----

将检测变换从多边形定义的平面图察到指定宽度和高度的直角平面

输入 / 输出
-----------

- 输入：图像 + 多边形坐标
- 输出：校正后的图像

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - output_size
     - 输出尺寸（宽x高）
     - 800x600

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 标记四个透视点。
3. 设置输出尺寸，点击保存。

注意事项
--------

- 用于俯视图转换或文档矫正。
