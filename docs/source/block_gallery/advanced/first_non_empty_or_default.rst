首先非空或默认值
==================

简介
----

取第一个非空数据元素或默认值

输入 / 输出
-----------

- 输入：多个可选值
- 输出：第一个非空值或默认值

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - default_value
     - 默认值
     - null

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置默认值。
3. 点击保存。

注意事项
--------

- 用于处理可能为空的数据流。
