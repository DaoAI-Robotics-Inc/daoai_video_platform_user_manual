.. _缓存获取:

缓存获取
==================

简介
----

从缓存条目中获取之前存储的值

输入 / 输出
-----------

- 输入：缓存键
- 输出：缓存值

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - cache_key
     - 缓存键名
     - 无

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 输入缓存键名。
3. 点击保存。

注意事项
--------

- 需要先使用Cache Set存储值。
