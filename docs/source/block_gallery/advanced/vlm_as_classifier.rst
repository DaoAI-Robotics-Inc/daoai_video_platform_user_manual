.. _VLM分类器:

VLM分类器
==================

简介
----

将原始字符串解析为分类预测

输入 / 输出
-----------

- 输入：图像 + VLM输出字符串
- 输出：分类结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - classes
     - 类别列表
     - 无

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 配置类别列表。
3. 点击保存。

注意事项
--------

- 用于将VLM文本输出转换为结构化分类结果。
