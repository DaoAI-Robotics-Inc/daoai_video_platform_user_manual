缓存设置
==================

简介
----

将值存储在缓存条目中以便后续检索

输入 / 输出
-----------

- 输入：键值对
- 输出：存储状态

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - cache_key
     - 缓存键名
     - 无
   * - ttl
     - 过期时间（秒）
     - 3600

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置缓存键名和过期时间。
3. 点击保存。

注意事项
--------

- 用于跨工作流共享数据。
