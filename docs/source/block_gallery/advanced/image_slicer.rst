图像切片
==================

简介
----

将输入图像分割为一系列较小的图像以进行小物体检测

输入 / 输出
-----------

- 输入：图像
- 输出：切片图像数组

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - slice_size
     - 切片大小（像素）
     - 640
   * - overlap
     - 重叠比例（0~1）
     - 0.2

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置切片大小和重叠比例。
3. 点击保存。

注意事项
--------

- 用于提高小目标检测准确率。
