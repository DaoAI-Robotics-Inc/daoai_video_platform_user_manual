动态区域
==================

简介
----

简化多边形，使其几何上方凸，并且仅包含所有需数据的顶点

输入 / 输出
-----------

- 输入：多边形坐标
- 输出：简化的凸多边形

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - simplification_level
     - 简化级别（0~1）
     - 0.5

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置简化级别。
3. 点击保存。

注意事项
--------

- 用于动态调整监控区域。
