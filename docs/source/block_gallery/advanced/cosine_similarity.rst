余弦相似度
==================

简介
----

计算两个嵌入向量之间的余弦相似度

输入 / 输出
-----------

- 输入：两个向量
- 输出：相似度值（0~1）

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - threshold
     - 相似度阈值
     - 0.8

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置相似度阈值。
3. 点击保存。

注意事项
--------

- 常用于人脸识别或特征匹配。
