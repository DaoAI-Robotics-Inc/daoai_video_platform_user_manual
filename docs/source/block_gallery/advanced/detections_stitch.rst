检测拼接
==================

简介
----

将对于多类输入图像的检测结果合并为某一检测结果

输入 / 输出
-----------

- 输入：多组检测结果
- 输出：拼接后的检测结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - stitch_mode
     - 拼接模式
     - auto

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择拼接模式。
3. 点击保存。

注意事项
--------

- 用于合并切片检测的结果。
