环境密钥存储
==================

简介
----

从环境变量中获取密钥

输入 / 输出
-----------

- 输入：环境变量名
- 输出：密钥值

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - variable_name
     - 环境变量名称
     - 无

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 输入环境变量名称。
3. 点击保存。

注意事项
--------

- 用于安全管理API密钥等敏感信息。
