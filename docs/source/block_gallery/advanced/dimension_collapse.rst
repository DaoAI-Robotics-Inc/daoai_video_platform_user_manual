.. _维度折叠:

维度折叠
==================

简介
----

将嵌套数据聚合为每个别列或位置组

输入 / 输出
-----------

- 输入：嵌套数据结构
- 输出：展平的数据

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - collapse_method
     - 折叠方法（flatten/merge）
     - flatten

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择折叠方法。
3. 点击保存。

注意事项
--------

- 用于处理多层嵌套数据。
