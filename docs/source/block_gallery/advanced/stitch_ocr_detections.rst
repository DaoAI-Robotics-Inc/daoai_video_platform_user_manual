拼接OCR检测
==================

简介
----

通过按空间对位置组织检测结果，将OCR检测结果组合成连串的文本字符串

输入 / 输出
-----------

- 输入：OCR检测结果
- 输出：拼接后的文本

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - direction
     - 拼接方向（horizontal/vertical）
     - horizontal
   * - spacing_threshold
     - 间距阈值（像素）
     - 10

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择拼接方向和间距阈值。
3. 点击保存。

注意事项
--------

- 用于将字符级OCR结果组合成完整文本。
