.. _表达式:

表达式
==================

简介
----

根据定义的输入变量和配置的规则创建特定输出

输入 / 输出
-----------

- 输入：变量 + 表达式
- 输出：计算结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - expression
     - 表达式字符串
     - 无

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 输入表达式（支持数学运算和逻辑判断）。
3. 点击保存。

注意事项
--------

- 支持Python语法的表达式。
