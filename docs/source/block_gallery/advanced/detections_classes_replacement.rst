检测类别替换
==================

简介
----

用单独分类模型预测的类别替换检测到的类别

输入 / 输出
-----------

- 输入：检测结果 + 分类结果
- 输出：更新后的检测结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - mapping_mode
     - 映射模式（replace/append）
     - replace

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择映射模式。
3. 点击保存。

注意事项
--------

- 用于两阶段检测（先检测再分类）。
