检测类别替换
==================

简介
----

用单独分类模型预测的类别替换检测到的类别。

输入 / 输出
-----------

- 输入：检测结果 + 分类结果
- 输出：更新后的检测结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 52 24

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 工作流中该节点的名称。
     - ``detections_classes_replacement_1``
   * - 备注
     - 可选备注信息，记录用途。
     - ``留空``
   * - 感兴趣区域
     - 检测模型的输出，描述将被替换类别的边界框。
     - 选择上游 ``检测`` 输出
   * - 分类结果
     - 基于感兴趣区域的物体分类模型输出。
     - 选择上游 ``分类`` 输出
   * - 备用类名
     - 当边界框未预测到类别时用于回退的类名。
     - ``unknown``
   * - 备用类ID
     - 当边界框未预测到类别时用于回退的类ID；否则自动生成。
     - ``77``
