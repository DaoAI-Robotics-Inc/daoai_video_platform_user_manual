属性定义
==================

简介
----

从模型预测中定义变量，例如类别名称、置信度或检测数量

输入 / 输出
-----------

- 输入：检测结果
- 输出：提取的属性

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - properties
     - 属性列表
     - class, confidence, count

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择要提取的属性。
3. 点击保存。

注意事项
--------

- 用于提取特定字段供后续模块使用。
