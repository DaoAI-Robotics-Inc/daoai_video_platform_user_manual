JSON解析器
==================

简介
----

将原始字符串解析为 JSON

输入 / 输出
-----------

- 输入：JSON字符串
- 输出：JSON对象

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - strict_mode
     - 是否严格模式
     - true

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 配置解析选项。
3. 点击保存。

注意事项
--------

- 用于处理API响应或配置文件。
