数据聚合
==================

简介
----

聚合工作流数据以仅在成或于时间间隔的统计信息

输入 / 输出
-----------

- 输入：数据流
- 输出：聚合统计信息

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - time_window
     - 时间窗口（秒）
     - 60
   * - aggregation_type
     - 聚合类型（sum/avg/max/min）
     - avg

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置时间窗口和聚合类型。
3. 点击保存。

注意事项
--------

- 用于生成统计报表或趋势分析。
