本地文件输出
==================

简介
----

将数据储存到本地文件

输入 / 输出
-----------

- 输入：任意数据
- 输出：本地文件

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - output_dir
     - 输出目录
     - ./output/
   * - file_format
     - 文件格式（json/txt/csv）
     - json

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 配置输出目录和文件格式。
3. 点击保存。

注意事项
--------

- 确保输出目录有写入权限。
