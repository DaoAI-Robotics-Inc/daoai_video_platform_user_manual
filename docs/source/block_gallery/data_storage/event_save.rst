事件保存
==================

简介
----

储存警报事件和一个图片、一段视频录像（可选）到数据库。

输入 / 输出
-----------

- 输入：事件数据 + 图像/视频
- 输出：保存状态

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - save_image
     - 是否保存图像
     - true
   * - save_video
     - 是否保存视频
     - false
   * - video_duration
     - 视频时长（秒）
     - 10

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 配置保存选项（图像/视频）。
3. 点击保存。

注意事项
--------

- 自动保存事件发生前后的视频片段。
