.. _事件保存:

事件保存
==================

简介
----

储存警报事件和一段视频录像到数据库。

.. 效果展示：
..   .. image:: ../images/data_storage/event_saver.png
..     :alt: Event Save Block Example
..     :align: center
..     :width: 40%
输入 / 输出
-----------

- 输入：原始图像，指定处理后的图像
- 输出：处理后的视频与自定义的报警事件

.. 适用场景
.. --------
.. - 需要保存特定事件的图像和视频片段以供后续分析时。
.. - 需要存档重要事件以满足合规性要求时。
.. - 方便检测员在监控画面中快速定位和回放关键事件。


参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值/ ``示例``
   * - **节点名称**
     - 步骤名称，用于标识该节点的唯一标识符
     - ``event_saver_1``
   * - **备注**
     - 可选的备注信息，用于描述该步骤的用途
     - ``留空``
   * - **事件类型**
     - 自定义事件的警报类型名称，用于标识不同类型的事件
     - ``违规操作``
   * - **输入图像**
     - 指定输入图像的来源，通常选择处理后的图像以确保保存的图像包含所需信息
     - ``label_visualization_1 image``
   * - **原始输入图像**
     - 指定原始输入图像的来源，不需要用户更改，保持原始的 ``input.image`` 即可
     - ``input.image``
   * - **是否保存视频**
     - 选择是否保存与事件相关的视频片段
     - ``True``
   * - **最大视频时长**
     - 设置保存视频的最大时长，单位为秒
     - ``30``
   * - **冷却时长**
     - 设置两次保存事件之间的最小间隔时间，单位为秒
     - ``60``
   * - **冷却键**
     - 用于区分不同事件的标识符，通常保持默认即可
     - ``留空`` 
   * - **事件冷却时长**
     - 设置同一种类事件发生后再次保存该事件的最小间隔时间，单位为秒
     - ``30``

.. 使用步骤
.. --------

.. 1. 在工作流编辑器中添加本模块。
.. 2. 配置保存选项（图像/视频）。
.. 3. 点击保存。

.. 注意事项
.. --------

.. - 始终保持原始输入图像为 ``input.image`` 以确保图像数据的完整性。
.. - 配置最大视频时长和冷却时长以优化存储使用。
