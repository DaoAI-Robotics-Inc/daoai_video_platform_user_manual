CSV格式化
==================

简介
----

按指定列创建CSV文件

输入 / 输出
-----------

- 输入：结构化数据
- 输出：CSV文件

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - output_path
     - 输出文件路径
     - ./output.csv
   * - columns
     - 列名列表
     - 自动

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 配置输出路径和列名。
3. 点击保存。

注意事项
--------

- 自动追加新数据到现有CSV文件。
