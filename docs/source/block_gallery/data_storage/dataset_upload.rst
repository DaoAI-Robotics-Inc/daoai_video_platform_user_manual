数据集上传
==================

简介
----
数据上传模块用于将工作流收集和处理后的图像和预测上传到DaoAI世界数据集。该模块方便用户将AI自动标注好的数据同步到DaoAI World平台，便于后续的数据管理和模型训练。通过配置上传参数，用户可以灵活控制上传频率和数据量，实现高效的数据存储和管理。

.. 效果展示：
..   .. image:: ../images/data_storage/dataset_upload.png
..     :alt: Dataset Upload Block Example

输入 / 输出
-----------

- 输入：图像 + 预测模型结果

- 输出：上传到指定UID的DaoAI World数据集

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值/ ``示例``
   * - **节点名称**
     - 步骤名称，用于标识该节点的唯一标识符
     - ``dataset_upload_1``
   * - **备注**
     - 可选的备注信息，用于描述该步骤的用途
     - ``留空``
   * - **输入图像**
     - 指定输入图像的来源，尽量保持为原始 ``input.image`` 以确保图片数据的完整性
     - ``input.image``
   * - **目标项目**
     - 选择要上传到的DaoAI World数据集的UID，UID一般为url的第二个 ``/`` 后面的部分. (例如: daoai.com/Keqg_LLfOQciTF2DFv1irg/ **PvIwJC6jg5tEWJUfdCaveg**/upload )
     - ``PvIwJC6jg5tEWJUfdCaveg``
   * - **预测显示**
     - 选择要上传的模型预测结果，通常选择检测模型的输出
     - ``detection_filter_1 predictions``
   * - **数据百分比**
     - 设置保存数据的百分比，范围0-100，随机上传百分比的数据来控制上传的数据量
     - ``100``
   * - **每分钟使用限制**
     - 设置每分钟上传的最大图像数量，防止上传过快导致服务器压力过大
     - ``10``
   * - **每小时使用限制**
     - 设置每小时上传的最大图像数量，防止上传过快导致服务器压力过大
     - ``100``
   * - **每日使用限制**
     - 设置每日上传的最大图像数量，防止上传过快导致服务器压力过大
     - ``1000``
   * - **使用配额名称**
     - 用于追踪使用配额的唯一标识符，保持默认即可
     - ``ggbond``
   * - **最大图像尺寸**
     - 设置上传图像的最大尺寸，超过该尺寸的图像将被缩放以节省存储空间
     - ``[1920,1080]``
   * - **压缩级别**
     - 设置图像压缩级别，范围1-100，值越大图像质量越高但文件越大
     - ``85``
   * - **注册标签**
     - 给开发人员用来设置的标签，一般保持为空即可
     - ``留空``
   * - **保留预测**
     - 是否将模型预测结果与图像一同保存，一般保持为True即可
     - ``True``
   * - **禁用接收器**
     - 布尔标志以禁用区块执行，保持默认False即可
     - ``False``
   * - **即发即忘**
     - 布尔标志用于多路复用执行，启用后区块不会等待上传完成再继续执行下游区块，保持默认True即可最大化执行效率
     - ``True``
   * - **标注批次前缀**
     - 用于为上传的图像分配批次名称的前缀，便于后续数据管理
     - ``auto_batch_`` 
   * - **标注批次创建频率**
     - 设置创建新标注批次的频率，可选包括：从不（never），每天（daily），每周（weekly），每月（monthly）
     - ``daily``

使用步骤
--------

#. 在工作流编辑器中添加本模块。
#. 输入DaoAI数据集UID。
#. 设置上传间隔，点击保存。

注意事项
--------

- 配置完后，启用工作流开始数据上传。
- 如果不知道预测结果符不符合要求时，可以先点击右上角的 ``测试`` 来用单张图像测试效果。图像会上传到DaoAI World数据集，方便查看效果。
