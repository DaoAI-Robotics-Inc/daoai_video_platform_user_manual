数据集上传
==================

简介
----

上传图像和预测到DaoAI世界数据集。

输入 / 输出
-----------

- 输入：图像 + 标注数据
- 输出：上传状态

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - dataset_id
     - DaoAI数据集ID
     - 无
   * - upload_interval
     - 上传间隔（秒）
     - 10

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 输入DaoAI数据集ID。
3. 设置上传间隔，点击保存。

注意事项
--------

- 需要配置DaoAI平台的API密钥。
