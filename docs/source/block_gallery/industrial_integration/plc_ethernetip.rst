.. _PLC EthernetIP:

PLC EthernetIP
==============

简介
----

通过 Ethernet/IP 协议与 PLC 通信，写入或读取寄存器/标签。

输入 / 输出
-----------

- 输入：待写入的数据或读写指令
- 输出：通信状态或读取结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 52 24

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 工作流中该节点的名称。
     - ``plc_ethernetip_1``
   * - 备注
     - 可选备注信息，记录用途。
     - ``留空``
   * - PLC 地址
     - 目标 PLC IP 地址。
     - ``192.168.1.10``
   * - 端口
     - Ethernet/IP 通信端口。
     - ``44818``
   * - 标签/寄存器
     - 读写的标签或寄存器标识。
     - ``MyTag1``
   * - 读写模式
     - read / write。
     - ``read``
   * - 写入数据
     - 当模式为 write 时写入的值。
     - 选择上游数据
