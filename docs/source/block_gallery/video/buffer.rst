缓冲区
==================

简介
----

返回传递给它的最后 'length' 个值的数组

输入 / 输出
-----------

- 输入：数据流
- 输出：缓冲数组

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - length
     - 缓冲区长度
     - 10

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置缓冲区长度。
3. 点击保存。

注意事项
--------

- 用于时序数据分析或平滑处理。
