异常检测
==================

简介
----

识别与先前数据相比的异常数入向量

输入 / 输出
-----------

- 输入：数据向量序列
- 输出：异常标记

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - sensitivity
     - 敏感度（0~1）
     - 0.7

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整敏感度。
3. 点击保存。

注意事项
--------

- 基于统计方法识别异常值。
