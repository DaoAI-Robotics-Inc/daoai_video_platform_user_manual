.. _线条计数:

线条计数
==================

简介
----

统计穿过线条的检测数量，可配置线段、计数判断点与检测源。

输入 / 输出
-----------

- 输入：检测/跟踪结果 + 线条坐标
- 输出：计数结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 52 24

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 工作流中该节点的名称。
     - ``line_counter_1``
   * - 备注
     - 可选备注信息，记录用途。
     - ``留空``
   * - Image
     - 输入图像来源。
     - ``input.image``
   * - 检测配置
     - 模型预测/统计计线定义来源。
     - 选择上游检测/跟踪输出
   * - 线条段落
     - 由两点组成的线段列表，如 ``[[0,0],[100,100]]``。
     - 点击绘制线条进入绘制页面进行绘制
   * - 判定点
     - 检测对象必须穿过线条才被计数的点，常用 ``CENTER``。
     - ``CENTER``
