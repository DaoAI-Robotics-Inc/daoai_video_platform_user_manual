线条计数
==================

简介
----

统计穿过线条的检测数量

输入 / 输出
-----------

- 输入：跟踪结果 + 线条坐标
- 输出：计数结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - line_position
     - 线条位置坐标
     - 无
   * - direction
     - 计数方向（单向/双向）
     - 双向

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 绘制计数线条并设置方向。
3. 点击保存。

注意事项
--------

- 常用于人流量统计、车流量统计等场景。
