.. _事件顺序:

事件顺序
==========

简介
----

跟踪事件完成情况并验证顺序，可用于按顺序检查指定动作标签。

输入 / 输出
-----------

- 输入：检测/跟踪结果 + 区域坐标
- 输出：按顺序验证的检查结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 52 24

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 工作流中该节点的名称。
     - ``event_order_1``
   * - 备注
     - 可选备注信息，记录用途。
     - ``留空``
   * - 输入图像
     - 用于元数据的输入图像。
     - ``input.image``
   * - 触发对象检测（已跟踪）
     - 触发对象的跟踪检测结果。
     - 需要object tracker输出的检测结果。
   * - 检查动作检测
     - 包含检查动作标签的所有检测结果。
     - 需要模型预测结果。
   * - 检查区域
     - 定义检查区域的多边形。
     - 点击绘制区域进入绘制页面
   * - 必需检查项
     - 必须完成的检查动作标签列表。
     - 自定义动作标签
   * - 强制顺序
     - 如果为真，检查必须按指定顺序执行。
     - ``False``
   * - 区域触发点
     - 区域检查的检测锚点。
     - ``CENTER``
   * - 置信度阈值
     - 检查检测的最小置信度。
     - ``0.5``
   * - 稳定窗口
     - 检查必须连续出现的帧数才确认。
     - ``3``
   * - 稳定阈值
     - 稳定窗口中必须包含检查的最小帧比例。
     - ``0.6``
   * - 进入确认帧数
     - 对象必须在区域内的帧数以确认进入。
     - ``2``
   * - 退出确认帧数
     - 对象必须离开区域的帧数以确认退出。
     - ``5``
   * - 最大处理时间（秒）
     - 一个处理周期的最大时间。
     - ``300``
