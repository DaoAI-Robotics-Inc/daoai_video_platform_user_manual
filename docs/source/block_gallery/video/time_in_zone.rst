区域内存在时间
==================

简介
----

在区域内跟踪对象时间

输入 / 输出
-----------

- 输入：跟踪结果 + 区域坐标
- 输出：停留时长

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - zone_coordinates
     - 区域坐标
     - 无
   * - min_time
     - 最小时长（秒）
     - 5

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 绘制监控区域并设置最小时长。
3. 点击保存。

注意事项
--------

- 用于滞留检测、停留时间分析等。
