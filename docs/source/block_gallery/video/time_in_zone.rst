区域内存在时间
==================

简介
----

计算检测对象在指定区域内的停留时长。

输入 / 输出
-----------

- 输入：检测/跟踪结果 + 区域坐标
- 输出：区域内停留时长

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 52 24

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 工作流中该节点的名称。
     - ``time_in_zone_1``
   * - 备注
     - 可选备注信息，记录用途。
     - ``留空``
   * - 图像
     - 本步骤的输入图像。
     - ``input.image``
   * - 检测
     - 需要object tracker输出的检测结果。
     - 选择上游检测/跟踪输出
   * - 区域
     - 目标区域的坐标，多边形点列表。
     - 点击绘制区域进入绘制页面
   * - 判定点
     - 目标需在区域内的判断点，常用 ``CENTER``。
     - ``CENTER``
   * - 移除区域外的检测结果
     - 如果为真，在区域外发现的检测结果将被过滤。
     - ``True``
   * - 离开区域时重置计时
     - 如果为真，在区域外发现的检测结果将重置时间。
     - ``True``
