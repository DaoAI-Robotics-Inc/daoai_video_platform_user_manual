检测稳定器
==================

简介
----

对对频帧应用平滑算法以减少噪声间隔

输入 / 输出
-----------

- 输入：检测结果序列
- 输出：平滑后的检测结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - smoothing_factor
     - 平滑因子（0~1）
     - 0.5

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整平滑因子。
3. 点击保存。

注意事项
--------

- 用于减少检测结果的抖动。
