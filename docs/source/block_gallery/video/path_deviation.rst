路径偏移
==================

简介
----

计算对象与参考路径之间的距离或距离

输入 / 输出
-----------

- 输入：跟踪结果 + 参考路径
- 输出：偏移距离

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - reference_path
     - 参考路径坐标
     - 无
   * - threshold
     - 偏移阈值（像素）
     - 50

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 绘制参考路径并设置阈值。
3. 点击保存。

注意事项
--------

- 用于检测轨迹偏离、越界等情况。
