.. _速度:

速度
==================

简介
----

计算跟踪对象的速度和速度，并进行平滑处理和单位转换

输入 / 输出
-----------

- 输入：跟踪结果
- 输出：速度值

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - unit
     - 速度单位（km/h, m/s）
     - km/h
   * - smoothing
     - 是否平滑
     - true

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 选择速度单位。
3. 点击保存。

注意事项
--------

- 需要相机标定才能获得准确的速度值。
