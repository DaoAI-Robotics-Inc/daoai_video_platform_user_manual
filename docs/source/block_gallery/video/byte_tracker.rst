.. _字节追踪器:

字节追踪器
==================

简介
----

通过 ByteTrack 跟踪并更新视频帧中的对象位置

输入 / 输出
-----------

- 输入：视频帧 + 检测结果
- 输出：跟踪结果（带ID）

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - track_thresh
     - 跟踪阈值
     - 0.5
   * - match_thresh
     - 匹配阈值
     - 0.8

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 调整跟踪和匹配阈值。
3. 点击保存。

注意事项
--------

- 基于 ByteTrack 算法，适用于多目标跟踪。
