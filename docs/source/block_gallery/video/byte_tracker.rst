.. _物体追踪器:

物体追踪器
==================

简介
----

通过多目标跟踪器在视频帧中为检测到的对象分配 ID 并持续跟踪，可用于高速公路、监控等场景的目标计数与轨迹分析。

输入 / 输出
-----------

- 输入：视频帧 + 检测结果
- 输出：带 ID 的跟踪结果

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 52 24

   * - 参数
     - 说明
     - 示例/ ``默认值``
   * - 节点名称
     - 工作流中该节点的名称。
     - ``highway_tracker_1``
   * - 备注
     - 可选备注信息，记录用途。
     - ``留空``
   * - Image
     - 输入图像来源。
     - ``input.image``
   * - 检测配置
     - 选择要跟踪的检测结果/目标。
     - 选择上游检测输出
   * - 轨迹激活阈值
     - 轨迹在场景中轨迹激活的置信度阈值，检测对象速度越快，该阈值应越低（范围0-1）。
     - ``0.25``
   * - 轨迹缓存丢失
     - 丢失轨迹时缓存的步数（帧数）。
     - ``1``
   * - 最低阈值
     - 过滤低置信度轨迹的阈值，同样检测对象速度越快，该阈值应越低（范围0-1）。
     - ``0.7``
   * - 最小连续帧数
     - 轨迹稳定所需的最少连续帧数。
     - ``1``
   * - 启用人员重识别
     - 是否启用 ReID 以在遮挡/离开后恢复 ID。
     - ``False``
   * - IoU 匹配阈值
     - IoU 匹配阈值（0~1），仅在启用 ReID 时使用。
     - ``0.5``
   * - ReID 最小相似度
     - ReID 配对最小相似度阈值（0~1），仅在启用 ReID 时使用。
     - ``0.35``
   * - 实例缓存大小
     - 实例缓存容量，用于判别新实例或已见实例。
     - ``16384``
