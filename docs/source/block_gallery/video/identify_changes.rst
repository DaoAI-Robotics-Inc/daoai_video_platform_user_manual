识别更改
==================

简介
----

通过较入问数识别与先前数据的差异

输入 / 输出
-----------

- 输入：当前数据 + 历史数据
- 输出：变化标记

参数
----

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - 参数
     - 说明
     - 默认值
   * - threshold
     - 变化阈值
     - 0.1

使用步骤
--------

1. 在工作流编辑器中添加本模块。
2. 设置变化阈值。
3. 点击保存。

注意事项
--------

- 用于检测场景或对象的显著变化。
