工作流保存失败怎么办？
-----------------------------

出现保存失败时，按以下步骤排查：

1. 在工作流编辑页面，点击顶部的 **信息图标（i）** 查看具体报错信息。
2. 检查必填参数是否完整（例如输入、模型、可视化和输出模块的关键参数）。
3. 确认工作流中各节点的连线无断链或循环错误。


相机运行后，FPS 过了几分钟仍然显示为 0？
------------------------------------------

这通常说明工作流在运行时出现异常（runtime error）可按以下步骤排查：

1. 连接至天眼服务器，将端口 **10350** 转发到本地。
2. 在浏览器访问 ``http://localhost:10350`` 的 **Tilt** 页面。
3. 点击打开 **Pipeline Manager**，查看日志与报错信息。

运行多路视频时，帧数很低怎么办？
-----------------------------------------

当多路视频并发运行时，若总帧率下降，可尝试以下优化：

1. 在 **摄像头输入** 页面，点击右上角的 **提升检测性能** 按钮。
2. 在 GPU 设置中适当增加模型实例数（每块 GPU 上可同时加载多个实例），以提升并发推理的整体吞吐量。
