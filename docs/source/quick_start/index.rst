DaoAI 天眼系统简介
====================

DaoAI 天眼系统是一套以 **AI 视觉工作流为核心的工业智能分析平台**，
帮助用户通过可视化方式快速搭建、部署和管理机器视觉应用，
实现从“数据接入”到“算法推理”，再到“业务决策”的全流程自动化闭环。

系统采用模块化工作流架构设计。用户可以通过拖拽和连接模块的方式，
将图像输入、模型推理、逻辑决策及结果输出等功能节点自由组合，
快速构建符合自身业务场景的 AI 视觉流程，而无需编写复杂代码或具备深度算法背景。

当工作流设计完成后，工作流引擎会自动调度各模块运行，
确保数据在各节点之间高效传递与协同处理，
将设计好的算法流程快速转化为可稳定运行的生产级应用。

DaoAI 天眼系统持续提供并扩展丰富的内置模块资源，包括：

- 图像检测、分类、分割等模型模块
- 大型多模态模型（LMMs）智能决策模块
- 规则引擎与业务逻辑模块
- 结果可视化与告警输出模块

用户可根据业务需求按需组合使用，构建灵活、可扩展的 AI 应用体系。

系统同时支持多种部署方式，包括本地私有化部署与云端部署，
可适配工厂产线、边缘设备、数据中心或云平台环境，
满足对实时性、安全性及算力弹性的不同要求。

通过 DaoAI 天眼系统，您可以：
------------------------------

- 使用先进的 AI 视觉模型，对图像和视频中的目标进行精准检测、识别与分析。
- 在工作流的任意阶段引入大型多模态模型（LMMs），实现复杂业务决策和智能判断。
- 通过可视化规则模块，将模型推理结果快速转化为符合行业场景的业务判定逻辑。
- 打通从模型验证、测试调优到现场部署应用的完整闭环。
